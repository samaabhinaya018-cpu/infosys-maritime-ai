# Maritime Freight Crisis – Route Optimization System

## 1. Overview

Milestone 1 focuses on developing the user authentication module using Python and Streamlit. It allows users to create accounts, log in, recover forgotten passwords, and access separate user and admin dashboards.

## 2. Features Built

- **User Login:** Login using a username or email and password.
- **User Signup:** Create an account with a security question.
- **Forgot Password:** Recover passwords using a security question or email OTP.
- **User Dashboard:** Provides a dashboard for logged-in users.
- **Admin Login and Dashboard:** Provides a separate interface for administrators.
- **Registered Users:** Displays registered users' usernames and email addresses.

## 3. Tech Stack

- **Python:** Application logic.
- **Streamlit:** Web interface.
- **SQLite:** User data storage.
- **JWT:** Token-based authentication.
- **Gmail OTP:** Email-based password recovery.
- **ngrok:** Provides a public URL for the Streamlit application.
- **Google Colab:** Runs the project notebook.

## 4. How to Run the Notebook

1. Open the project notebook in Google Colab.
2. Configure the required secrets, including the Gmail app password, JWT secret, ngrok token, and admin credentials.
3. Run the notebook cells in order.
4. Open the generated ngrok URL to access the Streamlit application.

**Security Note:** Do not upload passwords, tokens, or private credentials to GitHub.
